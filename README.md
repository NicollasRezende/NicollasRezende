## Projetos

Do mais recente ao mais antigo.

### 2026

**[urban-mobility-analytics](https://github.com/NicollasRezende/urban-mobility-analytics)** · *ago/2026*
Plataforma de dados fim a fim para micromobilidade urbana: ingestão de eventos sujos → Data Lake →
Data Warehouse dimensional → Data Quality → API e dashboard com IA generativa. 36 scripts SQL, 155 testes.
`Python` `BigQuery` `GCS` `FastAPI` `Django`

**[gameboy-emulator](https://github.com/NicollasRezende/gameboy-emulator)** · *jul/2026*
Emulador de Game Boy e Game Boy Color escrito do zero em Kotlin, validado pixel a pixel contra
dmg-acid2/cgb-acid2 e os testes do Blargg — mais uma ROM homebrew autoral feita para rodar nele. 641 testes.
`Kotlin` `JDK 21` `Assembly GB`

**[nikz](https://github.com/NicollasRezende/nikz)** · *jun/2026* · [nikz.vercel.app](https://nikz.vercel.app)
Meu portfólio: site interativo com animações e design próprio.
`Next.js 16` `TypeScript` `Tailwind 4` `Framer Motion`

**[abacapython](https://github.com/NicollasRezende/abacapython)** · *mai/2026* · [PyPI](https://pypi.org/project/abacapython/)
SDK Python não-oficial para o gateway AbacatePay: sync e async na mesma interface, modelos Pydantic v2,
retries com backoff, verificação de webhook HMAC e cobertura de 100% dos endpoints documentados.
`Python` `httpx` `Pydantic v2` `mypy --strict`

**[Hackman](https://github.com/NicollasRezende/Hackman)** · *abr/2026*
Guia Cidadão IA — assistente de serviços públicos do GDF, feito no Hackathon Brasília Virtual 2026.
Back-end orquestra um LLM em cima de APIs governamentais e dados abertos.
`Spring Boot` `React` `Vite` `OpenRouter`

### 2025

**[RAG-SYSTEM](https://github.com/NicollasRezende/RAG-SYSTEM)** · *out/2025*
Sistema RAG completo para perguntar sobre seus próprios documentos — 100% local, sem API paga.
`Python` `LangChain` `Ollama` `ChromaDB`

**[IA-RESUMER](https://github.com/NicollasRezende/IA-RESUMER)** · *jun/2025*
Transcrição e resumo de áudio/vídeo com Whisper + Ollama: 6 tipos de resumo, cache para evitar
reprocessamento e relatório de qualidade da transcrição.
`Python` `Whisper` `Ollama`

**[GIF-NK-Hub-](https://github.com/NicollasRezende/GIF-NK-Hub-)** · *jun/2025* · [demo](https://gif-nk-hub.vercel.app)
Hub de GIFs em front-end puro, sem framework.
`HTML` `CSS` `JavaScript`

**[NeuralNK](https://github.com/NicollasRezende/NeuralNK)** · *mai/2025*
Agente de Jogo da Velha treinado com Deep Q-Learning, com interface para jogar e treinar —
acompanhado de um [artigo](https://github.com/NicollasRezende/NeuralNK/blob/main/RedesNeurais.md)
sobre redes neurais profundas aplicadas a ambientes corporativos.
`PyTorch` `Tkinter` `DQN`

**[IMG-TO-PDF](https://github.com/NicollasRezende/IMG-TO-PDF)** · *mar/2025*
