## Sobre mim

Desenvolvedor back-end com 3+ anos de experiência em sistemas corporativos e portais
governamentais, atuando também no front quando o projeto pede.

Trabalho principalmente com **Java** (Spring Boot, Liferay) e **Python** (FastAPI, Flask,
Django), e no front-end com **React** e **Next.js**. Tenho experiência com PostgreSQL, MongoDB,
Redis, Docker, Kubernetes, mensageria e integração de APIs REST, além de autenticação com
Keycloak, OAuth2 e gov.br/CKPE.

### [urban-mobility-analytics](https://github.com/NicollasRezende/urban-mobility-analytics) · *ago/2026*

![Python](https://img.shields.io/badge/Python_3.12-3776AB?style=flat-square&logo=python&logoColor=white)
![BigQuery](https://img.shields.io/badge/BigQuery-669DF6?style=flat-square&logo=googlebigquery&logoColor=white)
![GCP](https://img.shields.io/badge/Cloud_Run_·_GCS-4285F4?style=flat-square&logo=googlecloud&logoColor=white)
![FastAPI](https://img.shields.io/badge/FastAPI-009688?style=flat-square&logo=fastapi&logoColor=white)
![Django](https://img.shields.io/badge/Django-092E20?style=flat-square&logo=django&logoColor=white)
![Testes](https://img.shields.io/badge/155_testes-0A9EDC?style=flat-square&logo=pytest&logoColor=white)
![SQL](https://img.shields.io/badge/36_scripts_SQL-CC2927?style=flat-square)

Plataforma de dados **fim a fim** para uma operação de micromobilidade urbana. O dado entra
cru — com duplicata de retry, timestamp invertido, ID órfão e valor absurdo — e sai como resposta
de negócio: quais estações estão saturando, quais bicicletas consomem manutenção demais, como a
receita se move ao longo do mês.

Cobre a cadeia inteira: ingestão → Data Lake → Data Warehouse dimensional → camada de Data
Quality → API → dashboard → assistente de IA generativa. Nenhuma etapa é caixa-preta.

### [mobile-int](https://github.com/NicollasRezende/mobile-int) · *ago/2026*

![Kotlin](https://img.shields.io/badge/Kotlin-7F52FF?style=flat-square&logo=kotlin&logoColor=white)
![Compose](https://img.shields.io/badge/Jetpack_Compose-4285F4?style=flat-square&logo=jetpackcompose&logoColor=white)
![FastAPI](https://img.shields.io/badge/FastAPI-009688?style=flat-square&logo=fastapi&logoColor=white)
![WebSocket](https://img.shields.io/badge/WebSocket-010101?style=flat-square&logo=socketdotio&logoColor=white)
![Latência](https://img.shields.io/badge/resposta_%3C100ms-brightgreen?style=flat-square)

Leitor NFC **universal**: encostou a tag, o app extrai tudo que o chip responder — sem filtrar
por tipo de cartão, sem exigir cadastro prévio — e manda o dump inteiro por WebSocket para um
backend que salva, decide e devolve a resposta em menos de 100 ms. Tem painel web mostrando as
leituras chegando ao vivo.

Nasceu de uma pergunta simples: *o que exatamente tem dentro desse cartão?*

### [gameboy-emulator](https://github.com/NicollasRezende/gameboy-emulator) · *jul/2026*

![Kotlin](https://img.shields.io/badge/Kotlin_2.2-7F52FF?style=flat-square&logo=kotlin&logoColor=white)
![JDK](https://img.shields.io/badge/JDK_21-ED8B00?style=flat-square&logo=openjdk&logoColor=white)
![Assembly](https://img.shields.io/badge/Assembly_GB-6E4C13?style=flat-square)
![Testes](https://img.shields.io/badge/641_testes_passando-brightgreen?style=flat-square)
![License](https://img.shields.io/badge/MIT-green?style=flat-square)

Emulador de **Game Boy e Game Boy Color escrito do zero** — CPU, PPU, APU, timers, MBCs.
Validado **pixel a pixel** contra as imagens de referência da comunidade (dmg-acid2, cgb-acid2)
e contra a suíte de testes do Blargg.

E não para no emulador: o repositório também traz uma **ROM homebrew autoral**, escrita em
assembly de Game Boy, feita para rodar nele. Primeiro a máquina, depois o jogo que roda nela —
os dois lados do cartucho.

### [abacapython](https://github.com/NicollasRezende/abacapython) · *mai/2026* · [PyPI](https://pypi.org/project/abacapython/)

![Python](https://img.shields.io/badge/Python_3.10+-3776AB?style=flat-square&logo=python&logoColor=white)
![Pydantic](https://img.shields.io/badge/Pydantic_v2-E92063?style=flat-square&logo=pydantic&logoColor=white)
![httpx](https://img.shields.io/badge/httpx-2B579A?style=flat-square)
![mypy](https://img.shields.io/badge/mypy_--strict-2A6DB2?style=flat-square)
![ruff](https://img.shields.io/badge/ruff-D7FF64?style=flat-square&logo=ruff&logoColor=black)
![Endpoints](https://img.shields.io/badge/100%25_dos_endpoints-brightgreen?style=flat-square)

SDK Python não-oficial para o gateway de pagamentos AbacatePay. **Sync e async na mesma
interface**, type hints completos sob `mypy --strict`, modelos Pydantic v2 com alias automático
camelCase ↔ snake_case, hierarquia de erros tipada por status HTTP, retries com backoff
exponencial + jitter em 429/5xx e verificação de webhook HMAC-SHA256 em tempo constante.

Publicado no PyPI, com CI. Projeto educacional, sem fins comerciais.
